# ADR-10. Image upload

- **Status:** Accepted (baseline)
- **Date:** 15 Oct 2026
- **Source:** [TRD section 10.3](../planning/01_TRD.md), row ADR-10. Copied from the baseline; wording not changed.

## Context

Image upload for TriageLens. See TRD section 10.3 for the full architecture.

## Options considered

Always, never, opt-in

## Decision

**Opt-in with consent.** Results-only is the default.

## Consequences

Not stated separately in the baseline. Add consequences here as they are learned, through a pull request.

## Revisit trigger

Reviewers need images to work (use opt-in).
