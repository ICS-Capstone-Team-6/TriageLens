# Architecture decision records

One short file per decision that is large or hard to undo (Team Rules 2). ADR-1 to ADR-12 are copied from TRD 10.3 as the baseline.

**Owner:** Kweku decides when the team cannot agree (Team Rules 2). The person who proposes a decision writes it.

## What goes here

- `NNNN-short-title.md` files built from `0000-template.md`
- Decisions that change a baseline requirement (record them in the Team Rules change log too)

## What must not go here

- Meeting notes or discussion threads. Record only the decision and the reasons for it.
- Edits to an accepted ADR's decision. Write a new ADR that supersedes it.
