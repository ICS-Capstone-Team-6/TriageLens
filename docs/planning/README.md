# Planning documents (baseline)

The baseline planning set, version 1.0, dated 15 Oct 2026: the TRD, the Product Backlog, the Sprint Plan, the Team Rules, and the backlog as CSV.

**Owner:** Kweku (document owner, TRD 1). Micheal keeps the Sprint Plan current through change control (Team Rules 12).

## What goes here

- `01_TRD.md`, `02_Product_Backlog.md`, `03_Sprint_Plan.md`, `04_Team_Rules_and_Requirements.md`
- `product_backlog.csv`, the source for the GitHub issues and the board
- `pdf/` for PDF copies, if any

## What must not go here

- In-place edits. These files are frozen. Change requirements through an ADR in `../adr/` and add a line to the change log in `04_Team_Rules_and_Requirements.md`.
- Notes, drafts or working documents. Put those in the living folders.
