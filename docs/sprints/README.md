# Sprints

One file per sprint with goal, exit criteria, review notes, retro, workload rating and velocity (Sprint Plan 2 and 3). Board snapshots also go here.

**Owner:** Micheal (project manager and scrum master)

## What goes here

- `sprint-0N.md`, `board-snapshot-YYYY-MM-DD.csv`

## What must not go here

- Changes to the sprint baseline. Those go through change control (Sprint Plan 5, Team Rules 12).
