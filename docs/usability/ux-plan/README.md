# UX plan (E8-01)

**Story:** E8-01 (NFR-USAB). **Owner:** Kweku. **Support:** Micheal. **Sprint:** 0.
**Acceptance criteria (Backlog E8-01):**

- [ ] Interview notes from 3 or more health workers ([notes template](interview-notes-template.md), filled copies in this folder as `interview-P1.md` and so on)
- [x] 3 user journeys ([user-journeys.md](user-journeys.md)). Drafted from TRD 6.3; check them against the interviews.
- [x] First screening reachable in 5 taps or fewer ([low-fi-flows.md](low-fi-flows.md), tap count: 4). Drafted; confirm in the usability rounds.

## Order of work

1. **Ethics first.** Interviews are human-subject work (Team Rules 9.8). Ask the IRB whether they are exempt before the first one ([ethics-pathway.md](../../ethics/ethics-pathway.md), section 2).
2. Recruit 3 or more participants through the clinic contact (E12-01, [clinic-contacts.md](../../ethics/clinic-contacts.md)).
3. Run the interviews with the [interview guide](interview-guide.md). One person asks, one person takes notes (pair with Micheal).
4. Write each session up within 24 hours with the [notes template](interview-notes-template.md).
5. Fill in [synthesis.md](synthesis.md). Then update the journeys and flows, and mark what changed.
6. Turn findings that need new work into Icebox stories with `/board-sync add` (swap rule).
