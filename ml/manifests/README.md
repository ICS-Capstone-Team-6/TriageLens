# ML manifests

Committed split manifests and data cards (ML-DATA-01, ML-DATA-02). The TRD repository layout also lists model cards here; this repo keeps them in `docs/model-cards/`.

**Owner:** Chelsea

## What goes here

- Split manifests (patient-level, with seed), data cards, licence register entries

## What must not go here

- Images or any patient-level data beyond IDs and split assignments.
